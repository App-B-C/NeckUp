# NeckUp

L'écran de votre téléphone s'embrume quand vous baissez la tête, et redevient net quand vous le relevez à hauteur des yeux.

## Installer

Sur un téléphone ou une tablette Android (Android 8 ou plus récent), téléchargez ce fichier puis ouvrez-le :

https://github.com/App-B-C/NeckUp/releases/latest/download/neckup.apk

Android vous demandera d'autoriser l'installation depuis votre navigateur. Ensuite, les mises à jour se font dans l'appli : Réglages → Appli et mises à jour.

## Confidentialité

NeckUp ne collecte aucune donnée personnelle. Vos statistiques restent sur votre appareil. L'appli se connecte à Internet uniquement quand vous recherchez une mise à jour.

Ce dépôt ne contient que les versions à installer.
